Recovering older messages

WhatsApp is queried gradually for older messages. Existing conversations and read states are preserved. The process resumes after restarts, and is paced one request at a time, with a 2,000-request/day operational safety ceiling (not a WhatsApp limit).

Conversation progress

Imported counts are estimates and can include duplicates. Short replies trigger another history request, not completion. Only a matched empty follow-up can suggest that no older messages remain. WhatsApp does not provide definitive per-thread completion; an unanswered request is never considered empty. The total for each conversation counts visible messages currently stored in this archive (not necessarily the full phone history). Use “Not complete — keep searching” to reopen a probably complete conversation. Stalled conversations need further investigation, not automatic deletion.

2. Save your recovery key

Your backups use AES-256-GCM encryption. Copy the recovery key to a password manager outside Home Assistant. Without it, a cloud backup cannot be restored if the server is lost.

3. Schedule & run

Backs up the current SQLite database without interrupting WhatsApp. Default: 05:30 UK time daily. The new encrypted backup is uploaded and checksum-verified before the older cloud copy is removed.

Download latest encrypted backup

There may briefly be two copies while a new backup uploads. Old cloud-provider trash, version history or internal snapshots may persist outside this app's control. Local media/attachments and WhatsApp login credentials are not in this database-only backup.
