2. Save your recovery key

Your backups use AES-256-GCM encryption. Copy the recovery key to a password manager outside Home Assistant. Without it, a cloud backup cannot be restored if the server is lost.

3. Schedule & run

Backs up the current SQLite database without interrupting WhatsApp. Default: 05:30 UK time daily. The new encrypted backup is uploaded and checksum-verified before the older cloud copy is removed.

There may briefly be two copies while a new backup uploads. Old cloud-provider trash, version history or internal snapshots may persist outside this app's control. Local media/attachments and WhatsApp login credentials are not in this database-only backup.
